## 2.5 接入层数据语义（两种接入方式的保真度差异）

| 能力 | xunji run（stream-json） | xunji connect（hooks） |
|---|---|---|
| 工具调用 span（输入/输出/错误） | ✔ | ✔ |
| llm_call span 与根 span | ✔ | ✘（hook 只见工具事件） |
| 步骤名/质量结论（工具信封约定） | ✔ | ✔ |
| 适用场景 | headless 定时任务、录制 | 交互式会话旁路 |

工具信封约定（`{"step","input","output","quality","status"}` 单行 JSON）是接入方工具的结构化输出规范，不依赖 Claude Code 内部机制；无信封时解析器回退到工具名启发式（低保真，仍 T1 可用）。
