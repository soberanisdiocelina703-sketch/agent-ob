## 原型覆盖（每个按钮可点、数据完整）

- **页面**：运行记录（8 条 Trace）/ 正常 Trace 详情 / 事故列表（4 簇 + 6 事故 + 6 组合筛选）/ 诊断工作台（症状、因果路径、Top-3 候选、证据卡、Trace 树）/ 成功失败 Diff（状态・传参・工具三维）/ 诊断复核（4 支持证据 vs 2 反证，三选一结论）/ 回归集与门禁 / 接入体检 / 设置。
- **主线演示**：事故 INC-2026-0814-003 → 诊断（规则先行、模型 1.1s 异步追加）→ 证据跳转原始事件驻留高亮 → Diff → 复核确认 → 一键转用例 REG-1041 → 复核不变量生效 → 门禁报告更新。
- **异常态**：断链警告与修复指引、证据不足候选折叠且复核禁用、质量未评估 Trace 基线按钮禁用、快照过期提示。
- **可访问性**：全键盘可达（Enter/Space/Escape）、`role=button`/`aria-modal`/`aria-live`、可见焦点环、`prefers-reduced-motion`、900px 以下响应式单列。
- 图标全部为内联 SVG（Lucide 风格线性、stroke 2px），无 emoji 图标。

## 自检脚本

两个脚本用 Playwright 真实渲染后测量，需先装浏览器内核（`python -m playwright install chromium`，或复用本机 Edge/Chrome）：

```bash
python midterm/check-deck.py       # 答辩稿：逐页对比度 + 溢出，5 种分辨率
python midterm/check-contrast.py   # 原型：全视图 WCAG AA 对比度
```

`check-deck.py` 会额外输出去重后的问题清单 `_deck_report.txt`（已 gitignore）。

## 生产就绪特性（2026-08-25 v2.0）

原型现已加固为生产就绪版本，主要改进：

### 错误处理
- **全局错误边界**：`window.onerror` 捕获运行时异常，显示友好错误页（含刷新按钮）而非白屏
- **渲染保护**：关键渲染函数包裹 `safeRender()`，单组件错误不影响整体

### 无障碍（WCAG AA+）
- **焦点管理**：模态框打开时捕获焦点、关闭时恢复至触发元素、Tab 键陷阱防止焦点逃逸
- **动态通知**：页面切换后通过 `aria-live="polite"` 区域通知屏幕阅读器当前页面标题
- **树形语义**：调用链路添加 `role="tree/treeitem"` 及 `aria-level/setsize/posinset` 完整层级信息
- **键盘完整**：所有交互均可通过 Enter/Space/Escape/Tab 完成，无键盘陷阱

### 性能优化
- **筛选防抖**：输入框 300ms 防抖，避免快速输入时频繁重渲染（减少 CPU/DOM 操作）
- **懒加载**：诊断工作台规则候选立即渲染，模型候选 1.1s 后异步追加（模拟真实 API 延迟）

### 离线可用
- **字体回退**：保留 Google Fonts CDN（性能优化），同时确保离线环境自动降级到系统字体（Segoe UI / Microsoft YaHei）
- **内联 Favicon**：data URI SVG 图标，无外部依赖

### API 就绪
- **数据层抽象**：`DataSource` 对象封装所有数据获取逻辑，现阶段返回硬编码数据，生产环境切换为 `fetch()` 调用即可（已预留代码注释）
- **状态管理**：集中式 `state` 对象 + 过滤器/诊断加载态/复核结论，易于对接真实后端

### 兼容性
- 保持单文件架构（无构建工具）、双击可开、全部离线可用
- IE 不支持（依赖 ES6 语法），现代浏览器（Chrome 90+、Edge 90+、Firefox 88+、Safari 14+）完整兼容
