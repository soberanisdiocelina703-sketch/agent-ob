# 更新日志

## [2.0.0-production] - 2026-08-25

### 生产就绪改进

#### 新增 ✨
- **错误边界**: 全局 `window.onerror` 捕获运行时异常，显示友好错误页而非白屏
- **无障碍增强**:
  - 焦点管理：模态框打开时捕获焦点、关闭时恢复、Tab 键陷阱防止逃逸
  - 动态通知：页面切换后通过 `aria-live` 区域通知屏幕阅读器
  - 树形语义：调用链路添加 `role="tree"` 及 `aria-level/setsize/posinset`
- **性能优化**:
  - 筛选输入防抖 300ms，避免快速输入时的频繁重渲染
  - 诊断工作台模型候选懒加载（1.1s 延迟），规则候选立即可见
- **元信息完善**:
  - 添加 `meta description` 和 `theme-color`
  - Favicon 改为内联 SVG data URI（罗盘图标）
- **数据层抽象**: `DataSource` 对象封装所有数据获取，现阶段返回硬编码数据，预留 API 集成接口

#### 改进 🔧
- 字体回退优化：保留 Google Fonts CDN 预连接，CSS 确保离线环境回退到系统字体
- 渲染保护：关键渲染函数包裹 `safeRender()`，单个组件错误不影响全局
- 代码质量：提取 `debounce` 和 `announce` 辅助函数，减少重复逻辑

#### 修复 🐛
- 修复模态框 ESC 关闭后焦点丢失问题
- 修复快速筛选导致的光标位置跳动

## [1.0.0] - 2026-08-24

初始版本，中期答辩演示原型。

### 功能
- 9 页完整工作台（运行/事故/诊断/Diff/复核/门禁/体检/设置）
- 九类故障分类（FM-01 ~ FM-09），主线演示 FM-07 检索排序漂移
- 双向证据复核流程（支持/反证/三选一结论）
- 回归集与门禁管理
- 响应式布局（900px 以下单列）
- 基础键盘可达（Enter/Space/Escape）
- WCAG AA 对比度达标

### 技术栈
- 纯原生 JS（无框架）
- 单文件架构（双击可开，无构建）
- 数据层：硬编码 `data.js`（487 行）
- 样式：token 系统 + 964 行 CSS
